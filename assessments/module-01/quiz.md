# Module 01 — Quick Quiz

## Питання 1
Що є коректним першим кроком quant-пайплайну?

A) Підбір "гарної" стратегії на око  
B) Data acquisition  
C) Торгівля в реальному часі  
D) Оптимізація Sharpe без даних

**Правильна відповідь:** B

## Питання 2
Чому використовують returns, а не лише рівень ціни?

A) Returns дозволяють порівнювати динаміку між інструментами  
B) Бо returns завжди додатні  
C) Бо price не змінюється  
D) Returns не мають шуму

**Правильна відповідь:** A

## Питання 3
Що таке data leakage?

A) Втрата файлу з даними  
B) Використання майбутньої інформації під час побудови/тесту моделі  
C) Висока волатильність  
D) Пропуски в датасеті

**Правильна відповідь:** B
