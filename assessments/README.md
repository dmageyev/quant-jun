# Оцінювання та формат міні-змагання

## Критерії оцінювання

1. **Слідування по лінії (30%)**
   - Робот тримає чорну лінію без частих сходів.

2. **P-контролер і стабільність (25%)**
   - Корекція руху пропорційна помилці, без хаотичних коливань.

3. **Калібрування двигунів (20%)**
   - Лівий і правий мотори узгоджені, рух на прямій стабільний.

4. **Проходження перехресть (15%)**
   - Робот проходить перехрестя за визначеним правилом.

5. **Командна робота і технічна дисципліна (10%)**
   - Ролі в команді, фіксація багів, культура тестування.

## Формат міні-змагання

- Кожна команда має 1 тестовий і 2 залікові заїзди.
- У підсумок іде кращий коректний результат.
- Штрафи:
  - сход з лінії — +5 сек;
  - пропуск перехрестя/неправильне проходження — +7 сек;
  - зупинка на трасі — +10 сек.

## Що вважається успіхом курсу

- Робот стабільно слідує по чорній лінії.
- Використано P-контролер.
- Виконано калібрування швидкостей моторів.
- Робот проходить перехрестя.
