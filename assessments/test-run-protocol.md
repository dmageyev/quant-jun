# Шаблон протоколу тестового заїзду

Використовуйте цей бланк для **тестових** (не залікових) заїздів під час налаштування.

## Мета тестового протоколу

- Фіксувати одну зміну за раз.
- Вимірювати вплив зміни на стабільність і час.
- Накопичувати дані для рішення, які параметри лишати у фінальній версії.

## Чек перед кожною ітерацією

- [ ] Змінено лише один параметр або один блок логіки.
- [ ] Попередній стабільний варіант збережено.
- [ ] Назва ітерації записана в протокол.

## Чек після кожної ітерації

- [ ] Зафіксовано час і штрафні події.
- [ ] Зафіксовано короткий висновок (що покращилось/погіршилось).
- [ ] Прийнято рішення: лишаємо зміну чи відкатуємо.
