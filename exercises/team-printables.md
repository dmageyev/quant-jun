# Друковані матеріали для команд

## 1) Чек-лист перед заїздом (1 аркуш на заїзд)

- [ ] Живлення робота перевірено.
- [ ] Напрямок обертання лівого/правого моторів коректний.
- [ ] Базові швидкості `L`/`R` зафіксовані.
- [ ] Значення `Kp` зафіксовано.
- [ ] Сенсори 1..8 читаються без «залипань».
- [ ] Лог виводить `ACTION`.
- [ ] Для P-контролера лог виводить `ERR`, `CORR`, `L`, `R`.
- [ ] Для перехресть лог виводить `CROSS`.
- [ ] Виконано 1 тестовий заїзд після останньої зміни.
- [ ] Змінено лише 1 параметр у поточній ітерації.

## 2) Картка ролей команди (1 аркуш на команду)

### Пілот
- Старт/стоп за командою викладача.
- Стежить за безпекою робота на трасі.

### Налаштувальник
- Вносить зміни у швидкості, `Kp`, правила перехрестя.
- Фіксує, який саме параметр змінено.

### Логер
- Записує ключові рядки debug-логу.
- Позначає номер заїзду і результат (успіх/помилка).

### Аналітик
- Пояснює причину помилки за логами.
- Пропонує одну наступну зміну для тесту.
