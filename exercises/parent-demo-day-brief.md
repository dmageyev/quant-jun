# Бриф для батьків / Demo Day

## Що вивчили діти за курс

1. **Базовий рух робота**
   - Старт, рух прямо, зупинка, плавні корекції.
2. **Робота з сенсорами лінії**
   - Зчитування 8 датчиків і прийняття рішень на основі їх стану.
3. **Принцип P-контролера**
   - Робот коригує траєкторію пропорційно величині помилки.
4. **Калібрування моторів**
   - Підбір `baseLeft/baseRight` для стабільного руху.
5. **Проходження перехресть**
   - Алгоритм дії на складних ділянках траси.
6. **Командна інженерна робота**
   - Ролі, тестові ітерації, фіксація рішень у протоколах.

## Що показати на Demo Day (5–7 хв на команду)

1. Коротко пояснити задачу робота (30–40 сек).
2. Показати один стабільний заїзд.
3. Пояснити, який параметр давав найбільший приріст результату (`Kp`, базові швидкості, логіка перехрестя).
4. Показати 2–3 рядки debug-логу і пояснити, що вони означають.
5. Назвати одну технічну проблему, яку команда вирішила.

## Простими словами про результат

- Діти пройшли повний цикл: **ідея → код → тест → аналіз → покращення**.
- Команди не просто «запустили робота», а побудували керування на базі вимірювань і логіки.
- Фінальний результат: робот стабільно тримає лінію, керує поворотами і проходить перехрестя.
