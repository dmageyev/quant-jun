# Exercise 01 — Market Data to Returns

## Мета

Перейти від "сирих" цін до базового набору returns для подальшого аналізу.

## Вхідні дані

Використай ряд:

`[120.0, 121.5, 121.5, 119.0, 122.0]`

## Завдання

1. Розрахуй simple return для кожного дня після першого.
2. Порахуй:
   - середню денну дохідність,
   - стандартне відхилення returns (sample std),
   - кількість днів зі спадом.
3. Коротко (2–3 речення) опиши, чи ряд виглядає стабільним.

## Критерії перевірки

- Формули застосовано коректно.
- Є чіткий список отриманих метрик.
- Висновок спирається на числа, а не інтуїцію.
