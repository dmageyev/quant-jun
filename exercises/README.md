# Практичні завдання (Exercises)

## Формат
- Кожне заняття завершується коротким практичним завданням.
- Команда здає: налаштування робота + результат тесту + короткий висновок.
- Для друку на заняття використовуйте `team-printables.md`.

## Вправи за заняттями

### Exercise 01 — Базовий рух
- Налаштувати рух вперед і зупинку.
- Довести повторюваність: 3 однакові старти без помилок.

### Exercise 02 — Читання сенсорів
- Вивести стани сенсорів 1..8.
- Пояснити, які сенсори активні на прямій ділянці.
- Додати в лог поле `ACTION` і пояснити, чому алгоритм обрав саме цю реакцію.

### Exercise 03 — P-контролер
- Запустити рух з P-корекцією.
- Підібрати робочий `Kp` і зафіксувати його.
- Додати debug-лог `ERR`, `CORR`, `L`, `R`, `ACTION` щонайменше для 3 різних ситуацій на трасі.

### Exercise 04 — Перехрестя
- Додати правило проходження перехрестя.
- Показати 3 успішні проходження підряд.

### Exercise 05 — Передзмагальний тюнінг
- Провести 3 контрольні кола.
- Зафіксувати найкращий час і стабільність проходження.
