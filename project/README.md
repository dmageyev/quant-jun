# Project Workspace (один файл на весь курс)

## Головна ідея

Команда працює над **одним і тим самим** файлом:

- `line_follower_project.ino`

Кожен модуль додає нову поведінку до цього файлу, а не створює окремий проєкт.

## Порядок роботи

1. Відкрити `line_follower_project.ino`.
2. Внести одну зміну.
3. Завантажити код на робота.
4. Зробити тестовий заїзд.
5. Зафіксувати лог і результат.

## Повні приклади по етапах

- `full-code-checkpoints.md` — повні кодові версії для занять 01..04.

## Фінальна ціль

Отримати стабільну фінальну версію у `line_follower_project.ino`, що:

- тримає лінію,
- використовує P-контролер,
- проходить перехрестя,
- має зрозумілий debug-лог.
