# Release Freeze Checklist (`line_follower_project.ino`)

Використовуйте перед фінальним заліковим заїздом, щоб зафіксувати стабільну версію.

## 1) Freeze коду

- [ ] Визначено фінальні значення: `Kp`, `baseLeft`, `baseRight`, `crossForwardMs`.
- [ ] Після freeze не змінюємо логіку без нового повного циклу тестів.
- [ ] Збережено копію фінального файлу `line_follower_project.ino`.

## 2) Перевірка поведінки

- [ ] 3 стабільні кола підряд без критичних збоїв.
- [ ] Робот проходить перехрестя за узгодженим правилом.
- [ ] Немає випадкових зупинок або небезпечних ривків.

## 3) Перевірка debug-логів

- [ ] У логах є `ERR/CORR/L/R/ACTION`.
- [ ] У логах є `S3-6/CROSS/ACTION` на перехрестях.
- [ ] Команда може пояснити щонайменше 3 приклади з логів.

## 4) Передстартова операційна готовність

- [ ] Заряд/живлення перевірено.
- [ ] Механіка/кріплення сенсорів перевірені.
- [ ] Протокол тестових і залікових заїздів підготовлено.
