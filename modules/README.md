# Модулі курсу MakerTime Robot Line Follower

Курс складається з 5 занять по 2 години.

1. `module-01-start-and-motion.md` — старт курсу, команди, піни, базовий рух.
2. `module-02-line-sensors-and-basic-follow.md` — робота з датчиками та просте слідування.
3. `module-03-p-controller-and-calibration.md` — P-контролер і калібрування моторів.
4. `module-04-full-run-and-debug.md` — повний заїзд, перехрестя, пошук багів.
5. `module-05-team-race.md` — командні змагання та підсумок.

Кожен модуль має структуру:
- Аналогія
- Архітектурна суть
- Практична перевірка
- Важливий момент
