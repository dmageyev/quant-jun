# Безперервна робота над одним файлом проєкту

Цей курс тепер ведеться як **постійний процес розвитку одного файлу**:

- `project/line_follower_project.ino`

Кожне заняття додає новий шар логіки у цей самий файл, без створення «нового проєкту з нуля».

## Як проходить робота по заняттях

1. **Заняття 01**: базовий рух і debug фаз.
2. **Заняття 02**: читання сенсорів і просте rule-based слідування.
3. **Заняття 03**: P-контролер і калібрування.
4. **Заняття 04**: перехрестя і повний заїзд.
5. **Заняття 05**: фінальний тюнінг під змагання.

## Приклади повного коду

Повні кодові версії по етапах:

- `project/full-code-checkpoints.md`

Фінальна інтегрована версія для заїздів:

- `project/line_follower_project.ino`

## Правило роботи команди

- В кожній ітерації змінюємо лише один параметр.
- Після зміни робимо один тестовий заїзд.
- Обов’язково фіксуємо лог (`ACTION`, `ERR/CORR/L/R`, `CROSS`) і висновок.
