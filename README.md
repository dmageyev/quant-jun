# quant-jun

Навчальний репозиторій курсу **"Quant Junior: Основи кількісних фінансів з Python"**.

## Для кого курс

- Junior developers, які хочуть зайти в quantitative finance
- Студенти фінансових/технічних спеціальностей із базовим Python
- Аналітики-початківці, які хочуть перейти до data-driven підходу

## Мета курсу

Дати практичну базу, щоб студент міг:

1. Працювати з ринковими часовими рядами
2. Рахувати базові метрики дохідності та ризику
3. Перевіряти прості гіпотези на історичних даних
4. Презентувати обґрунтовані висновки

## Структура репозиторію

- `.ai/` — AI Brain Center (стан, правила, handover)
- `modules/` — навчальні модулі курсу
- `exercises/` — практичні завдання
- `assessments/` — тести та критерії перевірки
- `llms.txt` — AI Manifest для агентів
