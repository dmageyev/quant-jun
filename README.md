# MakerTime Robot Line Follower (QUANT v.3)

Навчальний курс для дітей 10–12 років, де команди створюють і налаштовують робота, який стабільно слідує по чорній лінії, використовує P-контролер, проходить перехрестя та бере участь у міні-змаганні.

## Параметри курсу

- **Назва:** MakerTime Robot Line Follower
- **Аудиторія:** 10–12 років
- **Тривалість:** 5 занять × 2 години
- **Платформа:** Arduino Uno, Arduino IDE
- **Робот:** QUANT v.3
- **Сенсори:** 8 аналогових датчиків лінії (доступ через `bool`-функцію за номером 1..8)

## Навчальні цілі

1. Навчити базовому керуванню рухом робота.
2. Навчити читати сенсори лінії та будувати алгоритм слідування.
3. Впровадити P-контролер для корекції курсу.
4. Виконати калібрування швидкостей лівого/правого двигуна.
5. Реалізувати проходження перехресть і провести змагання.

## Структура матеріалів

- `modules/` — план і зміст занять
- `exercises/` — практичні завдання
- `assessments/` — критерії оцінювання та формат заїздів
- `exercises/team-printables.md` — друковані чек-листи та картки ролей
- `modules/teacher-quick-debug-guide.md` — швидкий довідник викладача з дебагу

Почніть з `modules/README.md`.
